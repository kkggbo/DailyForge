# Workout 前端页面说明

> 版本：v1.1
> 日期：2026-08-23

| 路由 | 鉴权 | 用途 |
|---|:---:|---|
| `/workout` | 是 | 当前训练工作台、Day 浏览、保存、打卡和最近记录 |
| `/workout/history/:sessionId` | 是 | 单条训练记录的只读详情 |

`/workout` 已加入应用导航和登录后首页入口。工作台顶部 header 除「管理训练模板」外，还提供「周期总结历史」入口（→ `/ai-coach/history?tab=cycle-summaries`）。

## 工作台状态

- `loading`：展示加载提示。
- `error`：展示明确错误和重新加载入口。
- `no_active_template`：引导至 `/cycle-templates`，不创建自由训练记录。
- `active + editable`：默认 Day 的 W2 已返回，允许填写、手动保存和完成打卡。
- `active + readonly`：展示 completed/cancelled 快照，禁止编辑。
- `active + preview`：展示未来计划，不创建 session。
- `cycle_completed`：提供再次使用当前模板、选择其他模板和 AI 占位入口。

## 训练填写

训练日默认展示计划参数，不要求逐项重复录入实际值。每个执行项通过“记录实际值 / 修改实际值”按需展开输入区；未填写的实际值会以 `null` 提交，由后端在动作正常完成时按计划值固化。参数输入仅允许非负数，整数型参数不允许小数，小数型参数最多两位。

动作完成状态位于动作卡片底部。失败 / 跳过原因仅在选择“部分完成、已跳过、未完成”后展示；选择“其他”时提示用户可在“感受/备注”补充说明。动作级“感受/备注”按需展开，并使用 `feedback` 字段保存和回显；训练级仅使用默认展示的 `notes` 训练备注输入框。完成打卡前检查每个动作状态；失败原因及实际参数仍为可选。休息日不展示动作输入，但支持填写训练备注并完成打卡。

## 完成后的行为

W5 成功后页面停留在刚完成的 Day，读取 `completedDay` 切换为只读，不自动跳转到下一 Day。若为周期最后一天，当前页面保留完成记录和周期完成提示；重新进入 `/workout` 后才显示完整的周期结束页。

## 历史详情

最近记录链接到 `/workout/history/:sessionId`。详情页通过 W6 获取快照，只展示计划参数、实际参数、状态、失败原因、感受与备注，不提供编辑入口。
