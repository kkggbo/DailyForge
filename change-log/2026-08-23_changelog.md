# 2026-08-23 Changelog

## 今日概览

本轮集中在「体验收口 + AI 能力打磨」：去掉开发向文案、统一中文展示，把 AI 入口回归业务上下文；重做了循环模板编辑页（动作默认折叠 + 时长秒/分钟拆分）、训练工作台（点卡片录实际值 + 自动保存）、AI 生成/周期总结页（隐藏内部数据、弹窗补资料、指标-结构校验、模型改 flash）。

## 今日完成内容

### 1. 登录 / 注册页

- `/` 改为登录页（登录即首页），`/login` 重定向到 `/`。
- 删除开发向的 LandingPage，把产品介绍（hero 标语 + 三张特性卡）融入登录页。
- 已登录用户访问登录 / 注册页时自动跳转到 `/app`。

### 2. 控制台 `/app`

- 由开发向 dashboard 改为「快速入门 + 功能入口」。
- 按训练状态条件渲染：无激活循环 → 快速入门；有循环 → 今天训练信息（模板名 / 训练日名 / 动作列表，休息日可直接打卡）；循环完成 → 重启入口。
- AI 解锁卡移到页面顶部，仅未开通 AI 的账号显示。

### 3. 个人资料 `/profile`

- 拆成三个页面：只读总览 `/profile`、编辑 `/profile/edit`、身体指标历史 `/profile/metrics/history`。
- 删除「当前资料完成度」banner 和 tab 切换。

### 4. 邀请码兑换页

- 删除开发文案；账户层级改用友好标签（普通用户 / AI 体验版 / 尊享版），AppShell 顶部同步。

### 5. 移除 AI Coach 独立 hub 页

- `/ai-coach` 重定向到 AI 模板生成；模板生成入口归入训练模板页，周期总结入口归入训练工作台，并补充周期总结历史入口。

### 6. 训练模板页

- 「Active Cycle」改中文；启用模板置顶；「AI生成」徽标不换行；正式模板 eyebrow 统一为「正式模板」。

### 7. 技术修复

- `crypto.randomUUID` 在纯 HTTP 下不可用导致 AI 功能报错，改为兼容非安全上下文的 UUID 生成。
- Vite 文件监听改轮询，避免 DSH 原子写导致本地 dev server 崩溃。
- 清理误提交的 tsc 构建产物（`vite.config.js`、`*.tsbuildinfo`）。

### 8. 循环模板编辑页优化

- 动作卡片默认折叠：只显示 动作序号 + 名称 + 操作按钮，点击「展开」再显示备注、标签与执行项，解决页面过长与滚动卡顿；折叠态仍有错误角标提示。
- 天级「全部展开 / 全部收起」快捷按钮；保存校验失败时自动展开并定位到第一个有错误的动作（支持跨天切换定位）。
- 时长单位拆分：新增「时长（分钟）」指标（长项目如跑步直接填分钟，上限 1440），原有「时长（秒）」保留用于短项目；打卡页指标单位改为中文展示（秒/分钟/次 等），只读/任务结果页单位同步中文化。

### 9. AI 模板生成：补资料改页内弹窗

- 「去补充资料」不再跳转个人资料页，改为页内弹窗，复用「基础档案 + 身体指标」两步表单；补完自动刷新可生成状态。
- 进入任务结果页时定位到第一个未完成状态的动作（该特性同时应用于训练工作台）。

### 10. AI 生成质量与模型

- RPE 指标改为「保留兼容、仅隐藏」：前端下拉不再提供、AI 不再生成该指标；存量数据仍可正常展示与校验。
- AI 输出新增「指标-结构」兼容校验：指标与动作结构不匹配时拒绝并触发修复，避免再给单段动作（椭圆机/动感单车/上坡快走等）配 RPE；结构→允许指标映射收敛到 `MetricKey` 单一来源。
- AI Coach 模型由 `deepseek-v4-pro` 改为 `deepseek-v4-flash`。

### 11. 训练工作台体验改造

- 实际值改为「点指标卡片就地编辑」：点卡片就地填该指标实际值，替代原先「展开整组再填」的流程。
- 手动保存改为 1.5s 防抖自动保存 + 顶部绿色「自动保存成功」toast。
- 完成打卡按钮回到底部；动作设完成状态后名称旁显示状态标签。
- 进入可编辑 Day 自动滚动到第一个未完成动作；删除粘性保存栏、组「已记录」徽标、进度条。
- 回到顶部按钮改为圆形 ↑ 箭头、视口底部居中（适配手机）。

### 12. AI 周期总结页

- 隐藏任务编号、循环 ID、模板 ID 等内部数据，统一中文展示。
- 任务页「返回周期总结」改为「返回训练工作台」（跳 `/workout`）；历史页周期 tab 按钮改「查看总结详情」并加黄色背景；「Cycle Summary」正文铺满卡片宽度。

## 总结

前端完成体验收口：去掉开发信息、统一中文、让 AI 入口回归业务上下文，并重做了循环模板编辑页与训练工作台的核心交互。AI 侧同步收敛：`duration_minutes` 指标键、RPE 隐藏、AI 输出「指标-结构」校验、AI 模型改用 `deepseek-v4-flash`，前后端契约文档已同步。全部改动已按 Conventional Commits 分次提交；子代理模型已配置为固定 `deepseek-v4-flash` + low 思考强度。
