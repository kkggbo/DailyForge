## 今日概览

## 今日完成内容

### 1. 饮食模块后端（diet）

**每日目标**
- Mifflin-St Jeor 估算 BMR → TDEE → 目标热量；按目标（减脂×0.85 / 增肌×1.10 / 维持）折算，下限 1200 kcal；宏量按蛋白每kg（1.8/2.0/1.6）+ 脂肪 25% + 碳水补足。
- 计算必需字段：性别 / 生日 / 身高 / 当前体重 / 训练目标 / **活动量**（新增）；缺任一即 `basis=null` + `missingFields`，无 sedentary 兜底。
- 支持自定义目标覆盖（`basis=custom`）与清除回自动（`basis=auto`）；自定义目标存入 `user_diet_targets`。
- `user_profiles` 新增 `activity_level` 列（V11 迁移），个人资料更新/读取接口扩展该字段。

**食物库**
- 系统种子食物 38 条（V12 迁移）；用户可上传自定义食物（每 100g 营养快照、全局共享、上传者昵称脱敏 `张**`）。
- 搜索关键词 / filter（全部 / 最近使用 / 最常食用 / 我的收藏）；收藏幂等。
- 食物来源标签（官方 / 用户）前后端透出。

**饮食记录**
- 每条记录按添加时食物资料做营养快照（每 100g × 克数 ÷ 100）；克数 1~5000。
- 每餐次 + 单日记录；可修改克数 / 餐次 / 日期、删除（仅本人）。

**摄入统计**
- 每日热量折线、宏量占比、周均值（有记录日均）、目标符合度（±10% 内天数/符合率；无目标为 null）。

**契约与文档**
- 接口 D1–D11，新增错误码 `FOOD_NOT_FOUND` / `FOOD_UPLOAD_INVALID` / `DIET_LOG_INVALID` / `DIET_TARGET_INVALID`。
- PRD / 接口 / 前后端 DDD / 数据库设计文档齐备（`docs/prd/diet_PRD.md` 等）。

### 2. 食物搜索分页

- `GET /diet/foods` 增加 `page`（默认 1）/ `pageSize`（默认 20，上限 50）与响应 `hasMore`，支撑选择食物时的无限滚动；recent/frequent 候选上限调至 500 保持多页一致。接口文档同步。

### 3. 本地联调修复

- **目标为 0 / 无补齐提示**：D1 摘要在资料不足时统一返回 `target=null`（原返回 basis=null 对象导致前端误判为有目标 → 卡片全 0、补齐提示不触发）。
- 日记页 / 摄入统计页在无目标时按 `missingFields` 展示「去补齐资料」提示；个人资料摘要卡新增**活动量**行展示。

### 4. 饮食日记页交互重构（依据联调反馈）

- **日期**：显示今天时隐藏「后一天」，不允许浏览/编辑未来日期。
- **今日摄入卡**：合并「每日目标」+「今日摄入」；有目标时总热量单独一行突出展示（大值+进度条），蛋白 / 碳水 / 脂肪均分同行；自定义目标按钮与恢复自动内嵌。无目标时只展示实际摄入（不画进度条），保留自定义目标 + 补齐资料提示（自定义后收起提示并展示进度）。
- **餐次卡片**：早 / 午 / 晚 / 加餐四卡一行均分，只显示餐次合计（热量大字 + 三宏量）；点击卡片在本行下方展开该餐明细（同一时间只展开一个）；右上角圆形「+」进入该餐添加。
- **添加流程**：点「+」直接进「选择食物」第一步（餐次自动绑定，无餐次下拉），列表分页滚动加载（默认 20 条、滚到底加载更多），行内含来源标签与快速收藏；选中后切「添加记录」第二步（克数 + 实时营养估算 + 保存）。
- **食物库收敛**：删除独立 `/diet/foods` 页面与路由；浏览/搜索/上传/收藏并入添加流程的选择食物面板；日记页头部改放「上传食物」按钮（选择食物面板内亦提供），上传后刷新列表可即时选用。
