# 2026-09-05 Changelog

## 今日概览

对上一轮上线的**饮食模块**与**个人资料**页做了一轮 UI/交互打磨与文档收尾：手机/窄屏适配优化、布局留白调整、活动量说明、若干文案说明，并把脱节的前端 DDD / PRD / 接口文档同步到与当前实现一致。

## 今日完成内容

### 1. 饮食模块 UI / 交互打磨

**日记页 `/diet`**
- 餐次卡片改为**任意宽度都一行均分**（`grid-cols-4`）：手机端四餐也保持同一行，窄屏自动压缩内边距、餐名与热量字号，宏量在窄屏改纵向小字、宽屏单行。
- 「+」圆形按钮修正为**正圆且内容居中**：触摸设备下不再被全局 `min-height:40px` 拉成椭圆（新增 `.df-round-btn` 豁免类）。
- 「今日摄入」卡：无目标（资料不足且未自定义）时，各营养素**名称与数值分行展示**并带单位（g / 千卡），不再与标签紧贴；隐藏进度条与目标值，保留「自定义目标」按钮与补齐提示。
- 页面两侧留白减半：内容容器左右 padding 减半、最大宽度 `max-w-7xl(1280px)` 放宽至 `1600px`，宽屏两侧空白同步收窄。

**统计页 `/diet/stats`**
- 「目标符合度」区块标题下新增一行说明：每天总热量落在当日目标 ±10% 内即算达标，只统计有记录的天数，符合率 = 目标内天数 ÷ 有记录天数。

### 2. 个人资料与账号相关

- **活动量说明**：`/profile` 基础档案卡「活动量」新增 `?` 图标，点击弹出弹窗列出 5 档活动量（久坐/轻度/中度/高强度/极高）的含义与例子，并注明会用于每日目标自动计算。
- **弹窗层级修复**：活动量说明弹窗改用 `createPortal(document.body)` 渲染，脱离卡片 `backdrop-filter` 造成的 fixed 包含块——此前弹窗固定在卡片内、不随滚动且被下层卡片遮挡。
- **「当前身体状态」卡**：删除「这里展示的是当前已知快照…」说明句，仅保留最近更新时间。
- `/profile` 与 `/profile/metrics/history` 身体指标网格密度调整：`<300px` 单列、`300–639px` 两列、`≥640px` 三列、`≥1280px` 四列，手机端每行展示更多指标。
- `/profile/edit`：保存基础档案 / 身体指标成功后，页面顶部弹出绿色 ✓ toast（约 2.5s 自动消失）。

### 3. AppShell / 导航

- 导航「统计」改名「**训练统计**」。
- 顶部导航由 `overflow-x-auto`（横向拖动）改为 `flex-wrap`：宽度不足时自动换行，不再需要左右拖动查看被藏起的模块入口。

### 4. 文档收尾

- `docs/frontend/diet_module/diet_DDD.md`：重写至 v0.3，同步删除的文件/组件（`DietFoodsPage`、`DietTargetCard`、`AddMealLogDialog`、`FoodPickerDialog`、`FoodDetailDialog`、`MealSection`）、新组件（`IntakeSummaryCard`、`AddMealFlowDialog`、`MealDetailPanel`、`MealRowItem`、`FoodSourceTag`）、食物库入口收敛、食物搜索分页、日记/添加/无目标交互，并补 profile 活动量说明。
- `docs/prd/diet_PRD.md`：§5 功能需求同步当前实现（无独立食物库页、添加两步流程、四餐卡片、日期限制、今日摄入合并与无目标展示、目标符合度说明、手机适配）。
- `docs/interfaces/diet_接口文档.md`：D5 总览参数补 `page/pageSize`，§5 前端调用顺序更新为当前交互（移除食物库页）。
